
# NIT Srinagar — Freshers' Campus Guide

A small React website that helps new students find their way around the NIT Srinagar campus. Click a pin on the campus map to see what the place is and how to get there.

Course project for Web Programming (ITL202), NIT Srinagar.
Made by [Person 1 name] and [Person 2 name].

## Requirements

- [Node.js](https://nodejs.org/) 20 or newer (comes with npm)

## Setup and run

```bash
npm install      # install packages (only needed once)
npm run dev      # start the dev server
```

Then open the address printed in the terminal (usually http://localhost:5173).

## Other commands

| Command           | What it does                                          |
| ----------------- | ----------------------------------------------------- |
| `npm run build`   | Creates an optimised production build in `dist/`.      |
| `npm run preview` | Serves the `dist/` build locally to check it.          |
| `npm run lint`    | Checks the code for common mistakes (oxlint).          |

## Editing place information

All locations are in [src/data/locations.js](src/data/locations.js). Fields set to `null` or `[]` are hidden on the site. Text marked `TODO: verify` still needs checking on campus.
